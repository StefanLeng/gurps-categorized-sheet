# Additional themes

Adds Expedition, Naval, Arcane, Space Operations, Cyberpunk, Gothic, Pulp / Cliffhanger, and Wasteland. Existing themes are retained, including Pulp / Historical. Uses the existing theme tokens, local font fallbacks, and existing decoration/accessibility switches. No external assets, dependencies, actor changes, or GURPS 4e rules changes.

This changeset is independent of the personal-appearance controls.
